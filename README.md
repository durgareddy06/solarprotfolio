# 6D Solar Portfolio 🚀✨

An interactive, high-performance 6D Solar System portfolio website built with HTML, CSS, JavaScript, FontAwesome, Google Fonts, and Three.js / Canvas animations.

## Features 🌟
- **6D Interactive Solar System**: Immersive background solar system animation with dynamic scroll tracking.
- **Glassmorphism UI**: Modern aesthetic with glowing neon accents (Cyan, Purple, Pink).
- **Custom Cursor & Smooth Micro-Interactions**: Premium interactive feel.
- **Responsive Layout**: Designed to look stunning on devices of all screen sizes.
- **Portfolio Sections**:
  - Hero & Introduction
  - Skills & Tech Stack
  - Featured Projects
  - Interactive Experience Timeline
  - Contact Information & Form

## Live Demo & Usage 💻
Simply open `index.html` in any modern web browser.
